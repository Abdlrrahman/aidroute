# Case Study: Last-Mile Cold-Chain Delivery in High-Risk Desert Corridors

## Context & Challenge

Delivering pediatric vaccines and surgical trauma kits from maritime entry ports (Misrata) to remote southern communities (Ghat, Ubari, Kufra) across 1,400+ kilometers of desert roads with fluctuating security threat levels, checkpoint extortion, and 45°C ambient temperatures.

## Solution Implemented

1. **Multi-Objective Route Optimization:** Replaced static coastal routes with dynamic risk-weighted routing that automatically bypasses active security flare-ups.
2. **Cold-Chain Protection:** Automated refrigerated reefer dispatch, ensuring vaccine shipments remain strictly within the 2°C - 8°C window.
3. **Ton-Km Financial Transparency:** Provided humanitarian program directors with instant $/ton-km breakdown to justify escort and driver risk premiums to institutional donors.

## Results

- **Zero Spoilage:** 100% of vaccine cargo delivered within temperature tolerances.
- **22% Transit Time Reduction:** Optimized checkpoint clearance planning reduced convoy bottlenecks by 6.5 hours on the Fezzan desert corridor.
