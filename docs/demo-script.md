# 5-Minute Portfolio Demonstration Script

1. **Minute 1: Overview & Regional Setting:**
   - Open `https://abdlrrahman.github.io/aidroute/`.
   - Switch language to **العربية** and back to **English** to demonstrate native RTL bilingual support.
2. **Minute 2: Route Optimization to Deep South (Ghat):**
   - In **Route Optimizer**, set Origin to **Misrata** and Destination to **Ghat**.
   - Show how switching optimization priorities (Fastest vs Safest) alters corridor selections.
3. **Minute 3: Cold-Chain Vaccine Dispatch:**
   - Navigate to **Cargo & Fleet Manifest**. Notice pediatric vaccines are selected and the system automatically mandates refrigerated reefer carriers.
4. **Minute 4: Crisis Shock Lab (Sirte Blockade):**
   - In **Shock & Crisis Lab**, activate the **Sirte Blockade** scenario.
   - Show how the routing engine dynamically re-routes the convoy inland via southern desert corridors.
5. **Minute 5: Cost Model & Ton-Km Economics:**
   - Review **Cost & Ton-Km Model** showing the multi-segment cost waterfall and $/ton-km efficiency benchmark.
